구글 스프레드시트 연동 방법

웹 서비스에 구글 스프레드시트 회비 현황을 실시간 연동하려면 시트를 "웹에 게시"해야 합니다.

  1. 연동할 구글 스프레드시트를 엽니다.
  2. 상단 메뉴에서 [파일] ➡️ [공유] ➡️ [웹에 게시]를 차례대로 클릭합니다.
  3. 게시 팝업 창에서 [링크]를 선택하고, 전체 문서 대신 [회비가 들어있는 시트 이름]을 선택합니다.
  4. 웹 페이지 대신 형식을 [쉼표로 구분된 값(.csv)]으로 변경합니다.
  5. [게시] 버튼을 누르고, 표시되는 긴 URL 주소를 복사하여 회비 관리 화면의 스프레드시트 URL 창에 붙여넣고 저장하세요.
팁: 첫 번째 열은 이름이어야 하며, 월별 열 이름은 '26.3.' 또는 '25.12.'처럼 '연도.월.' 형식으로 적어주시면 됩니다. 셀의 값은 'O' 또는 '연회비 완납'(연회비 단어가 들어간 텍스트) 등으로 채워두시면 완납으로 똑똑하게 자동 분류됩니다!
